# Сборка отчёта из выгрузок Excel

Скрипт собирает один сводный отчёт из нескольких «грязных» выгрузок: CSV из 1С и XLSX из Excel. Чистит дубли, строки «Итого» и «ВСЕГО», текстовые суммы вида `1 284,50 руб.`, разные форматы дат, лишние пробелы в категориях. На выходе — `report.xlsx` со сводной по месяцам, графиком и листом очищенных данных.

## Зачем это нужно

Ручная склейка выгрузок ломается на трёх вещах: итоговые строки внутри данных удваивают суммы, текстовые числа не складываются в Excel, а кодировка `windows-1251` превращает русские буквы в мусор. Скрипт закрывает все три и печатает контрольные суммы, чтобы результат можно было сверить.

## Быстрый старт

```bash
pip install -r requirements.txt
python src/build_report.py --input data/raw --output outputs/report.xlsx
```

Пример вывода:

```json
{
  "files": ["prodazhi_avgust2024.xlsx", "prodazhi_iyul2024.csv", "prodazhi_iyun2024.csv"],
  "rows": 102,
  "total": 1049788.6,
  "by_month": {"2024-06": 383338.42, "2024-07": 340762.48, "2024-08": 325687.7}
}
```

## Что делает скрипт

1. **Читает файлы** из папки: CSV определяет кодировку (`utf-8-sig`, `utf-8`, `cp1251`) и разделитель (`;` или `,`), в XLSX находит строку заголовка, даже если над ней есть объединённая ячейка с названием отчёта.
2. **Приводит колонки** к единой схеме: `дата`, `категория`, `менеджер`, `кол-во`, `сумма` — в любом регистре и на любом языке.
3. **Чистит данные**: убирает пробелы и `\xa0`, нормализует регистр категорий, парсит суммы (`1 284,50`, `1 391,20 руб.`, `1 000 ₽`, числа), даты (`01.06.2024` и `2024-07-18`), удаляет дубли и строки `Итого`/`ВСЕГО`.
4. **Строит сводную** по месяцам и категориям с итогами по строкам и столбцам.
5. **Пишет отчёт** в XLSX: оформленная шапка, числовой формат, закрепление, автофильтр, нативный график Excel и лист с очищенными данными и колонкой-источником.

## Структура

```
data/raw/           выгрузки: два CSV и один XLSX
src/build_report.py скрипт сборки
outputs/report.xlsx готовый отчёт
tests/              проверки парсинга и очистки
```

## Проверки

```bash
python -m unittest discover -s tests -v
```

Тесты проверяют разбор сумм и дат, удаление строк «Итого», устранение дублей и обязательные колонки.
